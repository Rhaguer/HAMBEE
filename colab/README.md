# HAMBEE EVA4 para Colab

Abre el notebook en Google Colab, pulsa **▶** en la única celda y carga el [ZIP de la entrega v1.1.0](https://github.com/Rhaguer/HAMBEE/releases/tag/v1.1.0) cuando aparezca el selector. Se requiere acceso a internet para instalar las dependencias. La ejecución en CPU procesa las 7.140 imágenes, comprueba la API, grafica la validación y el rendimiento, y ofrece un CSV descargable.
