# HAMBEE EVA4 para Colab

Abre el notebook en Google Colab, pulsa **▶** en la única celda y carga el ZIP de la entrega v1.2.0 cuando aparezca el selector. Se requiere acceso a internet para instalar las dependencias. La ejecución en CPU procesa las 714 imágenes originales, comprueba la API, grafica la validación y el rendimiento, y ofrece un CSV descargable. Admite el ZIP del repositorio si contiene una carpeta raíz `EVA4`; la entrega académica incluye esa estructura. Colab es una alternativa de demostración y no reemplaza las pruebas de Docker del pipeline.
