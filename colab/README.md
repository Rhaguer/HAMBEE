# HAMBEE EVA4 para Colab

1. Abre [Google Colab](https://colab.research.google.com/) y sube el archivo `HAMBEE_EVA4_Colab.ipynb`.
2. Selecciona **Entorno de ejecución → Ejecutar todas**.
3. Cuando se solicite un archivo, selecciona `EVA4_RHAGUER_YMALDONADO.zip` desde la [versión 1.0.1](https://github.com/Rhaguer/HAMBEE/releases/tag/v1.0.1).
4. La sesión instalará sus dependencias en un entorno virtual y ejecutará las pruebas. No hace falta GPU.

Para clasificar una imagen propia, cárgala en el panel de archivos e indica su ruta en la última celda.
El informe, API, modelo y evidencias están en el ZIP. Los resultados que imprime el notebook se calculan en la sesión actual.
